Design

  • Dropped the dark / cyan-violet gradient / glass-card look.
  • Swiss typographic layout: paper, ink, one red accent, strict grid, numbered sections.
  • Archivo variable font (width + weight axes) with JetBrains Mono for metadata.
  • Light and dark themes, with a toggle.
  • The print stylesheet is the CV: the PDF is generated from the same page.

Motion

  • Name letters animate in and stretch near the cursor (variable-font axes).
  • SBB-style split-flap board cycling through roles.
  • Profile statement lights up word by word as you scroll.
  • Timeline line draws itself; work index expands with a width-morphing title.
  • Side-project cards fill with ink from the cursor's entry point; tech marquee.
  • All motion is disabled when the system's reduce-motion setting is on.

Content
